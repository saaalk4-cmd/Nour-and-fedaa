# نُور وفداء 🌟

تطبيق Android عربي (RTL) لتعليم الأطفال المسلمين من 3 إلى 6 سنوات، يعمل بدون إنترنت.

- الإطار: Flutter + Riverpod + go_router + sqflite
- الخطة الهندسية: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## الحالة

- **تجربة تعلّم كاملة:** رحلة، مستويات وXP ونجوم، مهام يومية، أيام متتالية بلا ضغط، شارات وغرفة كؤوس، احتفالات، ومساعدة «لَمعة».
- **أقسام بمحتوى موثّق:** قرآني، صلاتي، أذكاري، أخلاقي الجميلة، سيرة نبينا ﷺ، شخصيات أحبها، قصص الأنبياء، أتعلم (دروس دنيوية حسب العمر).
- **تدريب تفاعلي** داخل كل قسم (أسئلة اختيار من متعدد) يمنح XP ونجومًا.
- **لوحة ولي الأمر** (PIN): تقرير لكل طفلة، الصوت، إظهار/إخفاء الأقسام، تعديل الاسم والعمر.
- يعمل بدون إنترنت (SQLite محلي + ملفات JSON في assets).

## مصادر المحتوى وكيف يُضاف

| القسم | الملف | المصدر |
|---|---|---|
| قرآني | `assets/content/quran_surahs.json` | [Tanzil](https://tanzil.net) (نص عثماني حرفي، لا يُعدَّل) |
| قصص الأنبياء | `assets/content/prophets_ayat.json` | Tanzil مع مرجع السورة والآية |
| أخلاقي/أذكاري/صلاتي/سيرة/شخصيات | `assets/content/*_hadith.json` | [موسوعة الأحاديث النبوية](https://hadeethenc.com) (راوٍ + كتاب + رقم + درجة) |
| أتعلم | `assets/content/learn_lessons.json` | محتوى تعليمي أصلي (غير ديني) |
| دروس التدريب | `quran_lessons.json`، `hadith_lessons.json`، `prophets_lessons.json` | **مولَّدة** من الملفات أعلاه |

- لإضافة حديث: أضفه في ملف القسم بكل الحقول (التطبيق والاختبارات يرفضان أي حديث ناقص)، ثم شغّل `python3 tools/generate_lessons.py`.
- لإضافة آيات أنبياء: عدّل المراجع في `tools/build_prophets_ayat.py` وشغّله على ملف Tanzil.
- «المعنى المبسّط» تحت كل نص صياغة تعليمية وليست من نص الحديث أو الآية؛ يراجعها ولي الأمر.

## الاختبارات

`flutter test`: منطق الألعاب، قاعدة SQLite حقيقية (sqflite_common_ffi: مكافآت، شارات، ترقية القاعدة، PIN، الاستخدام)، وصحة المحتوى الديني (المصدر، الأرقام، مطابقة نص الآيات).

## التشغيل محليًا

```bash
flutter create --org com --project-name nourfadaa --platforms android .   # مرة واحدة لتوليد مجلد android
flutter pub get
flutter run
```

## بناء APK

تلقائيًا: كل رفع إلى GitHub يشغّل `.github/workflows/build.yml`.
ثم من تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← `nour-fedaa-apk`.

يدويًا: `flutter build apk --release` (و`flutter build appbundle` لملف AAB).
