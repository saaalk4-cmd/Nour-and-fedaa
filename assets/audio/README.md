# صوت الدروس

ضع هنا ملفات الصوت (mp3) ثم اربطها بالدرس في ملف JSON:

```json
"audio": "assets/audio/t_adab_food.mp3",
"audio_license": "مصدر الترخيص أو صاحب الحقوق وشروط الاستخدام"
```

- **لا يُقبل `audio` بلا `audio_license`**: التطبيق يرفض الدرس.
- لا نضيف أي تسجيل قبل التحقق من ترخيصه للاستخدام التجاري داخل تطبيق باشتراك.
- القرآن: تسجيلات الشيخ المنشاوي (المرتل) بعد حسم الترخيص.
- الأذكار والآداب: صوت بشري واضح وبطيء يراجعه المراجع الشرعي.
- الدرس بلا `audio` يعمل بصوت محاكى (صمت) ويظهر في قسم الوالدين «الصوت: لم يُسجَّل بعد».
