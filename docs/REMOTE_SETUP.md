# إعداد «المتابعة من تليفون الأهل» (مرة واحدة، حوالي 10 دقايق)

الخدمة: **Firebase Firestore** من Google (الخطة المجانية Spark تكفي جدًا: التطبيق يكتب ملخصًا صغيرًا مرة كل 5 دقايق على الأكثر وهو مفتوح).
لا يحتاج التطبيق أي مكتبة Firebase: يتكلم مع الخدمة مباشرة (REST)، فلا يتغير حجمه ولا إعدادات أندرويد.

## الخطوات (على الكمبيوتر أو الموبايل من المتصفح)
1. ادخلي https://console.firebase.google.com بحساب Google بتاعك ← **Create a project** (أو Add project).
   - الاسم: مثلًا `nour-fedaa-family`.
   - Google Analytics: **مش محتاجينه** (اقفليه).
2. من القائمة: **Build ← Firestore Database ← Create database**.
   - Location: أي مكان قريب (مثلًا `eur3 (europe-west)`). **ده مش بيتغير بعدين.**
   - اختاري **Start in production mode**.
3. في Firestore افتحي تبويب **Rules**، امسحي اللي فيه، والصقي محتوى الملف `firestore.rules` من المستودع كله، ثم **Publish**.
4. من الترس ⚙️ جنب Project Overview ← **Project settings ← General**:
   - انسخي **Project ID**.
   - لو مفيش **Web API Key** ظاهر: تحت «Your apps» اضغطي أيقونة الويب `</>`، اكتبي أي اسم (مثلًا family)، **Register app** (من غير Hosting). هيظهر `apiKey` في الكود اللي بيطلع: انسخيه.
5. ابعتي لـClaude القيمتين: **Project ID** و**Web API Key**. (المفتاح ده مش سر: بيحدد المشروع بس، والحماية بالقواعد وبكود الأسرة.)
   Claude يكتبهم في `lib/features/remote/remote_config.dart` ويبني نسخة جديدة.

## الاستعمال بعد النسخة الجديدة
- **على تليفون البنات:** لوحة الأهل ← «المتابعة من تليفونك» ← شغّلي «إرسال التقدم لتليفون الأهل». هيظهر **كود الأسرة** (16 حرف).
- **على تليفونك:** سطّبي نفس الـAPK ← لوحة الأهل (اعملي PIN) ← «ده تليفوني: أتابع البنات منه» ← اكتبي الكود.
  من بعدها تليفونك يفتح على **متابعة البنات** على طول بعد الـPIN، واسحبي الشاشة لتحت للتحديث.
- **لإلغاء الربط:** في شاشة المتابعة ← القائمة ⋮ ← «إلغاء ربط التليفون ده». و«كود جديد» على تليفون البنات يقطع أي تليفون مربوط بالقديم.

## إيه اللي بيتبعت
لكل بنت: الاسم والسن، دقائق النهارده وآخر 7 أيام والإجمالي، النجوم، عدد الدروس، الأسبوع واليوم والمهمة الجاية، آخر 8 دروس (ومتقنة ولا تستاهل مراجعة)، عدد مرات اللعب. والحد اليومي لو موجود.
**ولا يتبعت أبدًا:** تسجيلات الصوت، الصور، الميكروفون، أو أي حاجة تانية من التليفون.
