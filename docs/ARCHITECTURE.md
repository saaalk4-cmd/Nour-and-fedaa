# نُور وفداء — الخطة الهندسية (Architecture)

## القرارات التقنية (ولماذا)

| القرار | الاختيار | السبب |
|---|---|---|
| الإطار | Flutter (Dart) | يبني Android بسهولة، دعم RTL ممتاز، ونفس تقنية تطبيقاتك الأخرى (بوصلة) فصيانته أسهل عليك |
| إدارة الحالة | Riverpod | بسيط، قابل للاختبار، يفصل الواجهة عن المنطق |
| التنقل | go_router | تنقل معلن واضح وثابت |
| قاعدة البيانات المحلية | sqflite | ناضجة ومستقرة وتعمل Offline بالكامل |
| المحتوى | ملفات JSON داخل assets | يمكن مراجعتها وإضافة محتوى جديد بدون تعديل الكود |
| الصوت | audioplayers (اختياري) | يعمل Offline من ملفات الأصول |
| بناء APK | GitHub Actions | لا يحتاج جهاز كمبيوتر |

## قاعدة: فصل المحتوى الديني

كل عنصر ديني له `source_type` من خمسة أنواع فقط: `quran`, `sahih_sunnah`, `seerah`, `scholars`, `educational`.
أي حديث يُخزَّن بحقول: النص، المصدر، الكتاب، رقم الحديث، الدرجة. وأي عنصر بلا مصدر يظهر في الدرس بوصفه «محتوى تربوي» فقط ولا يُنسب للنبي ﷺ.

- نصوص القرآن لا تُكتب يدويًا: تُستورد من مصدر موثوق (مثل مصحف المدينة / Tanzil بنص عثماني) وتُتحقق بفحص عدد الآيات لكل سورة.
- لا صور تجسّد الأنبياء أو الصحابة: رسوم رمزية فقط (أشكال، طبيعة، مساجد، نجوم).
- مواضع الخلاف الفقهي تظهر في «قسم الوالدين» فقط مع ذكر الخلاف.

## قاعدة البيانات

- `children(id, name, age, level, stars, points)`
- `progress(child_id, lesson_id, status, score, completed_at)`
- `badges(child_id, badge_id, earned_at)`
- `settings(key, value)` — يشمل PIN مُشفَّرًا بـ hash مع salt، وتفعيل/إيقاف الأقسام
- `usage_log(child_id, date, seconds)`

## الذكاء الاصطناعي

لن يُضاف في المرحلة الأولى. عند إضافته لاحقًا يجيب فقط من المحتوى المعتمد، وإلا يقول: «سأطلب من ولي الأمر مساعدتك.»

## المراحل

1. الهيكل + الشاشة الرئيسية + ملفا الطفلتين + لوحة ولي الأمر
2. محرك الدروس + «ما لا يسع الطفل المسلم جهله»
3. قرآني، صلاتي، أذكاري
4. السيرة، الشخصيات، قصص الأنبياء، أخلاقي
5. أتعلم (نور ٣ سنوات / فداء ٥ سنوات)
6. النجوم والإنجازات + Offline + الاختبارات
7. GitHub Actions + بناء APK
