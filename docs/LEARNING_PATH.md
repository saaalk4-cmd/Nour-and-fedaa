# مسار التعلّم (على طريقة دولينجو، بلا ضغط)

الشاشة الرئيسية بعد اختيار الطفلة هي **المسار** (`/path`)، لا شاشة الأقسام.

- **شريط عمودي ينزل لتحت**: أسبوع الطفلة الحالي كله، مقسوم لأيام. كل يوم ينتهي بهدية 🎁 تُفتح حين تُنجز كل مغامراته.
- **حالات العقد**: ⭐ منجزة (تُعاد متى أرادت) · الحالية تنبض وعليها لَمعة · 🔒 مقفلة (ترتيب صارم؛ عند لمسها يُقال «أكملي المغامرة السابقة أولًا»).
- **المصدر**: نفس `Curriculum.planFor` (التقدم لا التاريخ) عبر `Curriculum.pathFor`. فداء تأخذ `lessons`، ونور (≤4) تأخذ `earlyLessons` الصورية الصوتية.
- **الصوت أولًا**: ترحيب عند الفتح، وعنوان الدرس عند اللمس، وتهنئة عند الانتقال لمغامرة جديدة. لا تُنطق آيات ولا أحاديث.
- **«العب بحرية 🎮»** يفتح الشاشة القديمة بأقسامها كلها (لم يُحذف شيء). «رحلتي اليوم» ما زالت في تلك الشاشة.
- **ممنوع**: قلوب تضيع، سلاسل أيام مخيفة، لوحات صدارة، مقارنة بين البنتين، خصم نجوم.
- **الاختبارات**: `test/learning_path_test.dart` (منطق الترتيب الصارم، التوافق مع خطة اليوم، عمر نور، نهاية المنهج).
