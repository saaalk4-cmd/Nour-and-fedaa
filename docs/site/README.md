# صفحات الويب المطلوبة لـGoogle Play (غير منشورة)

- `privacy.html`: سياسة الخصوصية (مولّدة من `docs/privacy-policy-ar.md`).
- `delete-account.html`: صفحة طلب حذف الحساب من خارج التطبيق.

**قبل النشر:** املأ ما بين [أقواس مربعة] (الجهة، بريد الخصوصية، مدة تنفيذ الطلب)، وراجع السياسة قانونيًا.

**النشر:** أي استضافة ثابتة تعمل (GitHub Pages، Firebase Hosting على المشروع نفسه، أو موقعك). ثم ضع الرابطين في Play Console: «سياسة الخصوصية» و«حذف الحساب».
